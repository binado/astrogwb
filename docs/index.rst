astrogwb
========

``astrogwb`` models the stochastic gravitational-wave background from
compact-binary populations. It computes background spectra and detector
responses, simulates detector-pair cross spectra, and evaluates a Gaussian
network likelihood with optional population shot noise.

- :doc:`getting_started/quickstart` computes the overlap reduction function
  for the two LIGO detectors.
- :doc:`user_guide/catalog-inference` builds a reference catalog, predicts a
  background, and evaluates a likelihood.
- :doc:`user_guide/simulator-pipeline` covers the simulation API and CLI.
- :doc:`reference/api` documents the library's public interfaces.
